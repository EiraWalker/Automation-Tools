# Obsidian 对话归档

此词汇表约定 ChatGPT 对话保存到本地 Obsidian 时使用的领域语言。范围和未决选项见 [规划](plan.md)。

## Language

**归档问答**：用户点击某条回答的归档按钮时，该条回答及其对应的用户问题。
_Avoid_: 用“整个对话”指代一次归档的范围。

**回答版本**：同一问题的一次具体回答结果。重新生成的结果是新的回答版本，归档时作为新回答处理。

**目标库（Vault）**：用户选择的本地 Obsidian 笔记库，是对话归档的保存目的地。
_Avoid_: 把库根路径与库内文件夹混称为“保存位置”。

**目标文件夹**：目标库内用于存放本次归档笔记的目录。

**分类建议**：AI 根据归档问答、目标库目录树及已有标签提出的标题、目标文件夹和标签。
_Avoid_: 把 AI 建议称为已保存结果。

**保存预览**：实际归档前供用户编辑标题、目标文件夹和标签并查看最终文件路径的界面，不展示问答正文。

**归档笔记**：保存到目标库中的一问一答记录，正文保留原始问答，AI 建议用于其标题与分类信息。
