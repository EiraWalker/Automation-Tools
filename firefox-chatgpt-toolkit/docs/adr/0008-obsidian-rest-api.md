# 通过 Obsidian Local REST API 归档问答

首版通过目标库内的 Obsidian Local REST API 插件读取分类参考并保存归档，不增加独立本地后台服务。用户选择接受 Obsidian 必须运行且目标库插件已加载的限制，以减少额外服务的部署与维护；API 不可用时在 ChatGPT 网页右上角显示错误。

独立文件桥接可以在 Obsidian 关闭时写入任意已配置库，但需要新增常驻程序和目录、标签索引维护，因此本次不采用。首版只连接一个目标库，不实现多库切换；配置的库路径表示目标库，不让 REST 插件自动切换实际打开的库。具体产品规则见 [功能规划](../obsidian-export/plan.md)。

此决策已在 1.8.0 实现。重复归档直接覆盖；路径改变时先写入并读回核对新文件，再删除同一归档的旧文件。预览只显示可编辑的标题、文件夹和标签，以及最终路径。真实接口与浏览器证据见 [验证记录](../../userscripts/chatgpt-queue/VALIDATION.md)。
