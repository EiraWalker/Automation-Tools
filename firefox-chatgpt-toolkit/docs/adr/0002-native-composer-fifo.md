# ADR 0002：原生输入框与自动 FIFO

状态：已采纳。日期：历史决策追记 2026-10-10。

## 背景

用户要求接近 Codex CLI 的使用体验，删除独立消息文本框、加入队列按钮、运行按钮、折叠菜单和常规状态文字，并常驻快捷键提示。

## 决策

复用当前页面的原生 composer。Ctrl+Q 随时入队；回答进行中或存在待发条目时，Enter 入队；空闲且没有队列时，Enter 保持原生发送。Shift+Enter 换行，输入法选词不触发入队。

入队后自动等待前一回合结束，按当前队列顺序逐条发送，每条成为独立下一轮消息。用户可以调整待发顺序、删除或在原生输入框编辑条目。队列非空时直接显示，空时隐藏列表但保留 `Ctrl + Q  Enqueue`。

对比独立输入框与手动启动面板，原生 composer 消除第二份草稿与额外运行操作，也保留网页原生编辑行为。

## 影响

原生输入框有草稿或附件时等待。编辑期间暂停调度，保存后继续；取消编辑保留输入文字。Stop/Esc 暂停，空输入框 Ctrl+Q 可以接续待发队列。恢复和刷新后的队列默认暂停。

仅处理文字队列。新聊天先取得真实会话 ID，再发送后续条目；临时队列的迁移受同模式约束。开始运行即出队与完成后发送下一条的区别由 [ADR 0003](0003-receipt-active-errors.md) 定义。
